1. AI-generated design patterns

4. Bad spacing rhythm
5. Weak typography hierarchy
6. Empty whitespace
7. Poor visual balance
8. Misaligned elements
9. Weak CTA placement

PHASE 2 — COMPOSITION

Redesign composition first.

Do NOT start with components.

Create:

- visual hierarchy
- focal points
- reading flow
- balance
- rhythm

PHASE 4 — VISUAL SYSTEM

Use:

- depth
- subtle gradients
- atmospheric lighting
- layered composition

- random shadows
- heavy borders

PHASE 5 — TYPOGRAPHY

Typography must carry hierarchy.

Information should be grouped by:

- spacing
- scale
- contrast

Not by boxes.

- Apple

- unnecessary transitions

- stagger reveal

- smooth page transitions
